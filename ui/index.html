Telegram

          
…

          
Official Bot API — no ban risk. Setup: message @BotFather →
          /newbot, put the token in .env as
          TELEGRAM_BOT_TOKEN, restart, then open your bot and send
          /start <ASTA_TOKEN>. Chat + notifications both work here.

        


        

          
Teams bridge (read + send)

          
…

          
Uses your Teams web session (Playwright). One-time login:
          .venv/bin/python -m app.teams_bridge login — complete the Maersk SSO in
          the window. Then ask in chat: “read my Teams chat with Vinish” or “send Vinish: …”.
          Sessions expire every few weeks; you'll get a notification to re-login.
          Meeting-join is deliberately not supported.
